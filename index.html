Pengembangan web. Saat ini saya sedang belajar HTML, CSS, dan JavaScript, lalu ingin lanjut ke PHP dan MySQL supaya bisa membuat aplikasi web yang lengkap.

Saya pernah mengikuti Bootcamp Desain UI/UX yang diadakan DNCC pada tahun 2025. Dari sana saya belajar dasar-dasar merancang tampilan yang nyaman digunakan.

Halaman ini dibuat dengan HTML5 semantik, CSS (Flexbox, Grid, dan Bootstrap 4) untuk tampilan responsif, serta JavaScript untuk fitur interaktif seperti mode gelap, galeri, FAQ, dan validasi form. Kodenya dikelola dengan Git dan dipublikasikan melalui GitHub Pages.
